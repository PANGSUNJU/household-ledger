가계부 앱 개인정보처리방침

시행일: 2026년 10월 26일

팡이(이하 '운영자')는 '가계부 앱'(이하 '앱')을 운영하며, 이용자의 개인정보를 아래와 같이 처리합니다.

1. 처리하는 개인정보

항목내용언제
계정 정보로그인 방식(카카오·구글), 이메일, 이름 또는 닉네임, 계정 식별값로그인할 때 카카오·구글에서 받음
가계부 기록날짜, 금액, 가게 이름, 메모, 분류, 결제수단 이름, 고정 수입·지출, 예산, 가게 이름 고친 기록, 자주 쓰는 내역이용자가 입력하거나 저장할 때
설정화면 잠금 사용 여부와 비밀번호(복원할 수 없게 바꾼 값), 주간 알림 요일·시간설정을 바꿀 때
알림 정보알림을 받을 기기 주소와 기기 종류(예: Android Chrome)폰 알림을 켤 때만

영수증·캡처 이미지는 서버로 보내지 않습니다. 이미지 속 글자는 이용자의 기기 안에서 읽고, 이용자가 확인해 저장한 날짜·금액·가게 이름만 기록으로 저장합니다.

앱은 카드사·은행 계정 정보, 카드 번호, 계좌 번호를 요구하거나 수집하지 않습니다.

2. 이용 목적

가계부 기록 저장과 조회, 통계 표시, 이용자가 켠 알림 보내기, 로그인 유지에만 사용합니다. 광고나 마케팅에 쓰지 않고, 다른 곳에 팔지 않습니다.

3. 보관 기간

이용자가 계정을 삭제할 때까지 보관합니다. 계정을 삭제하면 위 정보가 모두 즉시 지워집니다.

4. 처리를 맡기는 곳 (위탁)

업체맡기는 일
Supabase Inc.계정과 가계부 기록 저장(데이터베이스), 로그인 처리
Cloudflare, Inc.앱 화면 파일 전송
카카오, Google소셜 로그인

Supabase 데이터베이스 위치: 대한민국 서울 (AWS ap-northeast-2)

5. 계정과 데이터 삭제

앱에서: 설정 → 계정 삭제 → '삭제' 입력 → 계정 삭제하기. 계정과 모든 기록이 즉시 지워지며 되돌릴 수 없습니다.

앱을 쓸 수 없을 때: 아래 연락처로 로그인에 쓴 계정(카카오·구글)과 이메일을 적어 삭제를 요청하면, 본인 확인 뒤 7일 안에 지웁니다.

삭제 전에 설정 → CSV로 내보내기로 기록을 받아 둘 수 있습니다.

6. 이용자의 권리

이용자는 언제든 자신의 기록을 앱에서 보고, 고치고, 지우고, CSV로 내려받을 수 있습니다. 그 밖의 열람·정정·삭제·처리 정지 요청은 아래 연락처로 하면 됩니다.

7. 안전 조치

모든 통신은 HTTPS로 암호화합니다. 데이터베이스는 행 단위 보안 규칙으로 본인 기록만 읽고 쓸 수 있게 막아 둡니다. 화면 잠금 비밀번호는 복원할 수 없는 값으로 바꿔 저장합니다.

8. 아동

앱은 만 14세 미만 아동을 대상으로 하지 않습니다.
