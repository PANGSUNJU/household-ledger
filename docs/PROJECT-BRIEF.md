# 개인 가계부 브리프
> 최종 갱신: 2026-10-14 | [확인]=사용자 확인 [가정]=검증 필요 [미확인]=질문 필요 [보류]=일부러 미룬 결정

## 1. 해결하려는 문제
- [확인] 통장·카드 사용 정보를 바탕으로 내 지출을 관리하고 싶다
- [확인] 기존 가계부 앱은 쓰다 보면 잊어버리게 된다
- [확인] 그만둔 이유는 입력이 귀찮고 관리가 어려워서였다 ← 1순위 문제
- [확인] 수익화는 생각하지 않는다. 가계부 기능을 잘 하는 앱에 집중한다

## 2. 성공 기준 (설계 결정의 심판 기준)
- [확인] ② 지출 한 건 등록이 10초 안에 끝난다
- [확인] ③ 밀린 내역을 일주일 치 몰아서 5분 안에 정리할 수 있다
- [확인] ④ 월말에 어디에 가장 많이 썼는지 앱을 열면 바로 보인다 (분류 기준·가게 기준)
- [가정] '잊어버림' 문제는 ③(빠져도 금방 따라잡기)이 대신 맡는다

## 3. 범위

### 이번에 한다

**입력**
- [확인] 1차는 나 혼자 쓰는 것을 목표로 한다
- [확인] 입력은 '사용자가 직접 올리는 이미지'와 '직접 입력' 두 가지뿐
- [확인] 이미지는 다 받는다: 종이 영수증, 전자영수증, 카드·은행 앱 내역 캡처
- [확인] 이미지에서 가져오는 것: 날짜, 금액, 가게 이름
- [확인] 가져온 값은 모두 수정할 수 있다 (저장 전 확인 화면 + 저장 후 캘린더에서)
- [가정] 읽은 결과는 한 번 보여주고 '저장'을 눌러야 등록된다
- [가정] 영수증에서 읽힌 품목은 메모에 자동으로 붙여두기만 한다 (확인·수정 없음)
- [가정] 이미지가 없는 결제는 직접 입력 (금액·가게만)
- [가정] 같은 지출 중복 등록 막기 (날짜·금액·가게·결제수단 기준)

**가게 이름**
- [확인] 가게 이름을 고치면 그 짝을 기억해, 다음에 같은 이름이 읽히면 고친 이름으로 미리 채운다 (기준 ②④)
- [가정] 1차는 글자가 똑같을 때만 적용한다
- [확인] 미리 채운 이름도 확인 화면에서 언제든 다시 고칠 수 있다

**결제수단**
- [확인] 자주 쓰는 카드·통장을 결제수단으로 등록해두고, 등록한 목록에서 사용자가 고른다
- [확인] 결제수단은 이미지에서 자동으로 고르지 않는다
- [확인] 등록 안 된 결제수단은 입력 화면에서 바로 등록할 수 있다
- [가정] 목록의 기본값은 '마지막으로 쓴 수단', 몰라도 '미지정'으로 저장 가능
- [보류] 기본값 세부 규칙 (가게별 / 전체 등) → 써보면서 결정

**분류**
- [확인] 분류는 확인 화면에 버튼으로 보여주고 탭해서 고른다
- [확인] 분류 목록은 사용자가 직접 정할 수 있다 (추가·수정·삭제)
- [확인] 분류별 통계를 낸다 (기준 ④)
- [가정] 전에 간 가게는 그 가게의 분류가 미리 선택된 상태로 나온다
- [가정] 분류를 안 고르면 '미분류'로 저장된다
- [가정] 시작용 분류 9개: 식비, 카페·간식, 생활용품, 교통, 쇼핑, 문화·여가, 고정지출, 저축/투자, 기타
- [보류] 처음 보는 가게의 분류 자동 추천 → 7단계에서 이미지 읽는 방식과 함께 판단

**보기**
- [확인] 캘린더에 가게 이름과 사용 총액을 보여준다 (예: 다이소 12,300원) (기준 ③)
- [가정] 월말 화면은 분류 기준·가게 기준 합계를 둘 다 보여준다 (기준 ④)
- [확인] 기록은 지우지 않고 계속 쌓는다
- [확인] 기본 화면은 '이번 달' 합계를 보여주고, 매달 0원부터 다시 쌓인다 (기준 ④)
- [가정] 지난달·전체 누적은 넘겨서 볼 수 있다
- [확인] 한 달 시작일 설정은 두지 않는다. 대신 통계 화면에서 보고 싶은 기간을 직접 고른다
- [확인] 통계 화면은 항상 '이번 달(1일~오늘)'로 열린다 (지난번 선택을 기억하지 않음)
- [가정] 기간 빠른 선택: 이번 달 / 지난달 / 최근 30일 / 직접 선택(시작일~종료일)

**고정비**
- [확인] 고정비를 따로 등록해둔다
- [확인] 고정비만 따로 리스트와 통계로 볼 수 있다
- [확인] 고정비마다 날짜가 주말에 걸리면 '앞 평일' / '뒤 평일' 중 무엇으로 잡을지 고를 수 있다
  (예: 월급 → 앞 금요일, 보험료·카드값 → 뒤 월요일)
- [가정] 1차는 매달 반복만 지원한다 (매년·매주 반복은 v2)
- [가정] 1차는 주말만 피한다. 공휴일까지 피할지는 열린 질문
- [확인] 월급도 고정 항목으로 등록한다 → 이 앱은 들어오는 돈(수입)도 기록한다
- [가정] 고정 항목은 '고정 수입'(월급)과 '고정 지출'(보험료 등)로 나눠 부른다
- [확인] 고정 항목의 금액·날짜는 수정할 수 있다 (예: 월급 인상)
- [가정] 수정하면 그 다음 회차부터 적용되고, 이미 기록된 지난 내역은 바뀌지 않는다
- [가정] 성과금·연말정산 환급처럼 한 번만 들어오는 돈은 '수입'으로 직접 입력한다 (지출 입력과 같은 화면에서 수입/지출만 바꿈)
- [가정] 연말정산 추가 납부처럼 한 번만 나가는 돈은 일반 지출로 입력한다
- [확인] 고정 항목은 그 날짜가 되면 자동으로 기록이 남는다
- [가정] 앱이 꺼져 있던 날의 고정 항목은 다음에 앱을 열 때 빠짐없이 채운다 (매일 0시 자동 실행은 서버가 필요할 수 있어 7단계에서 판단)
- [확인] 화면 표시: 오늘 이후 고정 항목은 캘린더에 '예정'으로 흐리게, 날짜가 지나면 실제 기록으로 바뀐다
- [확인] 통계(이번 달 1일~오늘)에는 실제 기록만 들어가고, 고정 항목 리스트에는 '이번 달 남은 예정 금액'도 보여준다
- [확인] 성과금·연말정산 등 한 번만 생기는 돈은 직접 입력, 고정 항목 수정은 다음 회차부터 적용 (위 제안 확정)

**공통**
- [확인] 등록된 모든 기록은 수정할 수 있다

**아직 빈 곳 (기본 가계부 기능 점검 결과)**
- [확인] 기록 종류는 지출·수입 두 가지만 둔다 (이체 종류를 따로 만들지 않음)
- [확인] 저축·적금·투자 납입은 '저축/투자' 분류로 관리한다
- [확인] 할부는 가계부에서 따로 관리하지 않는다 (사용자가 원하는 방식으로 입력)
- [확인] 카드값·내 계좌끼리 이체·결제 취소·환불은 별도 기능 없이 사용자가 알아서 입력·수정한다
- [가정] 이미지에서 읽은 결과에 취소 건이 섞이면 확인 화면에서 사용자가 빼거나 고친다
- [확인] 기록을 삭제할 수 있다
- [확인] 전체 내역 목록 보기와 검색 (가게·메모·금액)
- [확인] 결제수단 종류: 현금 / 카드 / 계좌이체
- [가정] 카드·계좌이체는 개별로 등록(예: 신한 체크, 토스 통장), 현금은 하나로 둔다
- [확인] 통계에서 저축/투자를 소비 합계와 따로 보여준다
- [확인] 정리하라고 불러주는 알림을 넣는다 ('잊어버림' 대책)
- [가정] 1차 알림은 주 1회 정리 알림, 요일·시간은 사용자가 정한다 (예: 일요일 밤 9시)
- [미확인] 선택한 배포 방식에서 운영비 0원으로 알림을 보낼 수 있는가 (7단계에서 확인)
- [확인] 데이터 내보내기는 CSV 파일로 한다
- [가정] 엑셀에서 열었을 때 한글이 깨지지 않게 만든다
- [보류] CSV 가져오기(기기 옮길 때 다시 넣기)까지 할지 → 7단계 데이터 보관 방식과 함께 결정
- [확인] 예산 관리를 넣는다
- [가정] 1차 예산은 '한 달 총예산' 하나만: 사용 금액·남은 금액·남은 날 기준 하루 쓸 수 있는 금액을 보여준다
- [가정] 예산 기간은 매달 1일~말일, 저축/투자 분류는 예산 계산에서 뺀다
- [가정] 분류별 예산, 예산 80% 도달 알림은 v2

**금액이 매달 다른 고정 지출**
- [확인] 날짜가 되면 금액을 채우지 않고 '금액 입력 필요' 상태로 보여주고, 사용자가 입력하도록 유도한다
- [가정] 고정 지출을 등록할 때 '금액 고정 / 매달 다름'을 고른다
- [가정] 캘린더에 '통신비 · 금액 입력 필요'처럼 눈에 띄게 표시하고, 입력 전에는 통계·예산에 넣지 않는다
- [가정] 입력이 필요한 고정 지출은 한곳에 모아 보여주고, 주간 정리 알림에도 "금액 입력 필요 N건"으로 알려준다
- [확인] 카드값 중복 문제는 별도 기능으로 막지 않고 사용자 판단에 맡긴다

**데이터**
- [확인] 기기를 바꿔도 내 데이터를 이어서 쓸 수 있어야 한다
- [보류] 그 방법 (백업 파일 / 직접 계정 / 토스 로그인 / 나만 쓰는 서버) → 7단계에서 배포 방식과 함께 결정

### 이번에 안 한다 (v2 상자)
- [확인] 은행·카드사 자동 연동
- [확인] 결제 알림·문자 자동 수신 (기술적으로 어렵고, 알림 미신청자도 많음)
- [확인] 수익화 전체 (광고, 인앱 결제 등)
- [가정] 품목 단위 상세 관리 (품목별 수정·통계)
- [가정] 비슷한 가게 이름 묶기 (예: '아성다이소'가 들어가면 모두 '다이소')
- [가정] 다른 사람이 쓰는 기능 (회원 관리 등)
- [가정] 매년·매주 반복되는 고정비
- [가정] 분류별 예산, 예산 80% 도달 알림
## 4. 핵심 시나리오
- [가정] 시나리오 1 — 결제 직후 (기준 ②)
  다이소에서 결제하고 영수증(종이·전자)을 받는다. 이미지를 올리면 날짜·가게·금액이 채워지고,
  가게 이름은 전에 고친 '다이소'로, 분류는 '생활용품'으로, 결제수단은 마지막으로 쓴 카드로 미리 골라져 있다.
  확인하고 저장. 10초.
- [가정] 시나리오 2 — 일요일 밤 몰아서 정리 (기준 ③)
  캘린더를 열면 기록이 빈 날이 보인다. 모아둔 영수증 사진을 올리고,
  영수증이 없던 결제는 카드 앱 내역 화면을 캡처해 올린다. 중복은 걸러진다. 5분.
- [가정] 시나리오 3 — 월말 돌아보기 (기준 ④)
  월급날 전날 앱을 열면 이번 달 분류별·가게별로 가장 많이 쓴 곳이 첫 화면에 보인다.

## 5. 제약
- [확인] 혼자 만드는 프로젝트
- [미확인] 1차 목표 시점
- [미확인] 주당 투입 가능 시간
- [가정] 월 운영비 0원 → 이미지 읽기는 무료 방식 안에서 고른다
- [미확인] 1차 기간 동안 기기 변경이나 여러 기기(폰+PC) 사용이 필요한가
- [확인] 요즘은 종이 영수증을 거의 받지 않는다
- [가정] 카드 내역에는 가게 이름과 총액만 있고 품목 정보는 없다
- [확인] 앱이 결제 알림을 자동으로 받아올 수는 없다
- [확인] 이미지에서 카드번호·카드사는 읽지 않는다 (개인정보 위험 원천 차단)
- [가정] 결제수단은 사용자가 넣은 별칭·종류만 저장한다
- [가정] 이미지 원본은 읽고 나면 지운다
- [확인] 배포 방식은 웹앱을 선호한다 (7단계에서 성공 기준과 알림·데이터 보관 조건을 확인하고 확정)
- [가정] 웹앱이면 폰과 PC 모두에서 쓸 수 있다
- [미확인] 웹앱에서 운영비 0원으로 주간 알림을 보낼 수 있는가 (특히 아이폰)
- [확인] 앱인토스에서 토스 로그인을 쓰려면 사업자 등록이 필요하다

## 6. 열린 질문
- [미확인] 이미지에서 날짜·가게·금액을 얼마나 정확히 읽을 수 있는가
- [미확인] 카드 앱 내역 캡처 한 장에서 여러 건을 제대로 나눠 읽을 수 있는가
- [미확인] 앱인토스 미니앱이 사진첩·공유하기로 이미지를 받을 수 있는가
- [미확인] 앱인토스 미니앱이 로그인 없이 기기에 데이터를 저장할 수 있는가
- [미확인] 기존 가계부 앱과 비교해 무엇이 다른가 (내가 이걸 계속 쓸 이유)
- [미확인] 고정비 날짜를 공휴일까지 피하게 할 것인가 (운영비 0원으로 공휴일 정보를 받을 방법이 있는가)
