# 안드로이드 앱(APK)으로 설치하기 — 갤럭시용, 0원

> 지금 웹앱을 안드로이드 앱 파일로 **감싸는** 방식(TWA)이에요. 앱을 열면 우리 웹앱이 주소창 없이 꽉 차게 떠요.
> 코드는 그대로이고, GitHub에 올려 배포하면 **앱도 바로 새 버전**이 돼요 (APK 를 다시 만들 필요 없음).
> 플레이스토어 없이 내 폰에만 설치해요.

## 먼저 준비
- 배포가 끝나 있어야 해요 (`docs/DEPLOY.md` 2~3번). 배포 주소를 열면 로그인 화면이 나오는 상태.
- 아래에서 `<배포주소>` 는 `https://household-ledger.○○.workers.dev` 예요.

## 1. 앱 파일 만들기 (PC 브라우저, 5분)
1. https://www.pwabuilder.com 접속 → `<배포주소>` 입력 → **Start**
2. 점검이 끝나면 **Package For Stores** → **Android** → **Generate Package**
3. 옵션 (나머지는 기본값 그대로)
   | 항목 | 값 |
   |---|---|
   | Package ID | 지금 앱: `dev.workers.pang7163y.household_ledger.twa` (다시 만들 때도 같은 값이어야 같은 앱으로 업데이트돼요) |
   | App name / Short name | `내 가계부` / `가계부` |
   | Signing key | **Create new** (새로 만들기) |
4. **Download** → zip 파일을 풀면 이런 파일이 있어요
   | 파일 | 쓰는 곳 |
   |---|---|
   | `…apk` | **폰에 설치할 앱 파일** |
   | `assetlinks.json` | 앱과 웹 주소가 같은 주인이라는 증명 → 2번 |
   | `signing.keystore`, `signing-key-info.txt` | 앱 서명 열쇠와 비밀번호. **비밀번호 관리자 등 안전한 곳에 보관**, GitHub 에 올리지 않기 (앱 이름·아이콘을 바꿔 APK 를 다시 만들 때만 필요) |
   | `…aab` | 플레이스토어용 (지금은 안 씀) |

## 2. 주소창 없애기 (assetlinks.json 올리기)
zip 안의 `assetlinks.json` 내용을 저장소의 `public/.well-known/assetlinks.json` 에 덮어쓰고 GitHub 에 올리면 끝이에요.
(지금은 `[]` 빈 파일이 들어 있어요. 안 바꿔도 앱은 열리지만 위에 주소창이 보여요)
- 내용은 앱 이름과 서명 지문이라 공개돼도 괜찮아요. Claude 에게 붙여 주면 대신 올려 드려요.
- 확인: `<배포주소>/.well-known/assetlinks.json` 을 열었을 때 그 내용이 보이면 성공.

## 3. 갤럭시에 설치
1. `.apk` 파일을 폰으로 옮기기 (카카오톡 '나에게 보내기', 구글 드라이브, USB 등)
2. 폰에서 파일을 누르기 → "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용** (카카오톡·내 파일 등 그 앱에만)
3. "Play 프로텍트" 경고가 나오면 **자세히 → 무시하고 설치** (직접 만든 앱이라 구글이 모르는 것뿐)
4. 앱 서랍에 **가계부** 아이콘이 생겨요. 설치 후엔 '출처를 알 수 없는 앱' 허용을 다시 꺼도 돼요.

## 4. 설치한 앱에서 되는 것
- **캡처 공유로 바로 입력**: 카드 앱·갤러리에서 캡처를 **공유 → 가계부** → 캡처 화면이 열리고 바로 읽어요 (여러 장도 OK)
- **아이콘 길게 누르기**: '기록 추가', '캡처로 입력' 바로가기
- **폰 알림**: 설정 → 알림 → 이 폰으로 알림 받기 (`docs/DEPLOY.md` 8번 설정 후). 처음에 안드로이드가 알림 허용을 물어봐요.
- 로그인·화면 잠금·모든 기능은 웹과 같아요. 기록도 같은 곳(Supabase)에 저장돼서 PC 웹과 함께 써요.

## 자주 묻는 것
| 궁금한 것 | 답 |
|---|---|
| 앱을 고치면 APK 를 다시 설치해야 하나요? | 아니요. GitHub 에 올리면 배포 주소가 바뀌고, 앱은 그 주소를 열어서 바로 새 버전이에요 |
| 위에 주소창이 보여요 | 2번 assetlinks.json 이 아직 빈 파일이거나, 배포가 안 끝났어요. 앱을 완전히 닫았다가 다시 열어 보세요 |
| 공유 목록에 '가계부'가 없어요 | 앱을 한 번 열어 로그인한 뒤 다시 해 보세요. 폰을 재부팅하면 목록이 새로 고쳐지기도 해요 |
| 크롬이 꼭 있어야 하나요? | 네, 갤럭시엔 기본으로 있어요. 앱이 크롬의 화면 엔진을 빌려 써요 |
| 나중에 플레이스토어에 올리려면? | 같은 zip 의 `.aab` 와 서명 열쇠로 올려요. 그때 다시 안내할게요 |
