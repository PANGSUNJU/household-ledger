# dev 브랜치 변경 목록 (아직 배포 안 됨)

`dev` 에 모아 두고, 확인이 끝나면 `main` 에 합쳐 한 번에 배포해요.
배포하고 나면 이 목록은 비우고 "배포 기록"으로 옮겨요.

## 배포 대기
- [ ] **연월 선택**: 캘린더·내역 위쪽 'YYYY년 M월'을 누르면 연월 선택 창이 떠요. 해는 ‹ › 로 넘기고 달을 누르면 그 달로 이동, '이번 달로' 버튼. (화살표 이동도 그대로)
- [ ] **달 바꿀 때 깜빡임 없애기**: 새 달 기록·예산을 다 불러온 뒤 아래 내용을 한꺼번에 바꿔요. 예산 카드가 잠깐 사라지거나 달력이 위아래로 움직이던 문제 해결.
- [ ] **예산 카드 모양 통일**: 예산이 있을 때·없을 때 같은 높이. 없을 때는 '○월 예산 · [예산 정하기]' / '○원 썼어요' / '예산 없음'. '하루 ○원'은 아래 줄 오른쪽으로.
- [ ] **수입 − 지출**: 캘린더 요약 카드 아래에 '수입 − 지출 = ○원' 한 줄 (남으면 파란색, 넘으면 빨간색 -). 지출은 저축/투자 포함, 환불 반영.
