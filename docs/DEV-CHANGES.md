# dev 브랜치 변경 목록 (아직 배포 안 됨)

`dev` 에 모아 두고, 확인이 끝나면 `main` 에 합쳐 한 번에 배포해요.
배포하고 나면 이 목록은 비우고 "배포 기록"으로 옮겨요.

## 배포 대기
- [ ] **연월 선택**: 캘린더·내역 위쪽 'YYYY년 M월'을 누르면 연월 선택 창이 떠요. 해는 ‹ › 로 넘기고 달을 누르면 그 달로 이동, '이번 달로' 버튼. (화살표 이동도 그대로)
- [ ] **달 바꿀 때 깜빡임 없애기**: 새 달 기록·예산을 다 불러온 뒤 아래 내용을 한꺼번에 바꿔요. 예산 카드가 잠깐 사라지거나 달력이 위아래로 움직이던 문제 해결.
- [ ] **예산 카드 모양 통일**: 예산이 있을 때·없을 때 같은 높이. 없을 때는 '○월 예산 · [예산 정하기]' / '○원 썼어요' / '예산 없음'. '하루 ○원'은 아래 줄 오른쪽으로.
- [ ] **수입 − 지출**: 캘린더 요약 카드 아래에 '수입 − 지출 = ○원' 한 줄 (남으면 파란색, 넘으면 빨간색 -). 지출은 저축/투자 포함, 환불 반영.
- [ ] **'가게' → '사용처 / 입금처'**: 입력 화면 칸 이름이 지출·환불이면 '사용처', 수입이면 '입금처'. 통계 '사용처별' 탭, 캡처 결과 칸, 내역 검색 안내, 환불 찾기, 자주 쓰는 내역, CSV 머리줄도 같이.
- [ ] **달력 칸 단순하게**: 날짜 칸에는 그날 총수입(파란 +)·총지출(빨간 -)만. 사용처 이름은 빼고, 자세한 건 날짜를 눌러 아래 목록에서. 예정 고정 항목은 '예정'만.
- [ ] **맨 아래 기록이 + 버튼에 가리던 문제**: 캘린더 아래쪽에 + 버튼 자리만큼 여백 추가.
- [ ] **날짜별 합계 없애기**: 캘린더 아래 그날 목록 제목의 지출 합, 내역 탭 날짜 묶음의 '지출·환불·수입' 합계 제거 (그날 수입·지출은 달력 칸에서).
- [ ] **목록 지출 금액 빨간색**: 캘린더 그날 목록·내역 탭에서 지출은 빨강, 수입·환불은 파랑 (요약 카드·달력 칸과 같은 색).
- [ ] **분류 네모 글자 잘림 개선**: 두 글자에서 자르던 것을 최대 네 글자 두 줄로 (카페/간식, 생활/용품, 저축/투자). 세 글자는 한 줄. 목록·자주 쓰는 내역 공통.
- [ ] **목록 회색 줄 정리**: 분류·결제수단을 빼고 **메모만 최대 2줄** (낱말 단위로 줄바꿈, 넘치면 …). 메모 없으면 줄 없음. 환불은 '수수료 ○원'. 분류가 없으면 네모에 '미분류'. 결제수단은 기록을 눌러 확인.
- [ ] **결제수단 다시 보이기 (금액 아래 작은 글씨)**: 메모와 자리를 나눠 오른쪽 금액 아래에. 체크·신용 구분용.
- [ ] **통계 기간 '올해' 추가**: 1월 1일~오늘 (작년 같은 기간과 비교). 결제수단별 탭과 함께 보면 카드별 합계.
- [ ] **기록 추가 화면에서 바로 분류 추가**: 지출·수입 모두 '+ 분류 추가' → 그 자리에서 이름·색 정하고 '추가하고 고르기' (설정으로 안 나가서 쓰던 내용 유지). 같은 이름이면 새로 안 만들고 그 분류를 고름.
- [ ] **'캡처로 입력' 버튼 지출·수입 모두 + 위에 고정**: 수입 탭에도 보이고, 화면을 내려도 위 줄이 붙어 있어 언제든 누를 수 있음.
- [ ] **저장하면서 자주 쓰는 내역에도 추가**: 지출 새 기록의 저장 버튼 위 '☐ 자주 쓰는 내역에도 추가' (매번 꺼진 채 시작). 체크하고 저장하면 저장한 사용처·금액·분류·결제수단으로 등록, 같은 내용은 두 번 안 넣음.
- [ ] **환불 수정 때 사용처 같이 바뀌기**: '어떤 구매를 환불받았나요?'에서 다른 구매를 고르면 사용처(와 결제수단)도 그 구매 것으로 바뀜. 사용처를 직접 고쳐 적었으면 그대로 둠.
- [ ] **환불은 수입처럼 안 보이게 (회색)**: 계산은 그대로(지출에서 뺌). 달력 맨 위 지출 아래 '환불 ○원 빠짐'(있을 때만), 통계 요약에 '환불로 빠짐 ○원'(있을 때만). 달력 칸에서 환불만 있는 날은 파란 + 대신 회색 금액. 목록 환불 금액은 + 없이 회색.
- [ ] **환불 고르는 방법을 두 칸 탭으로**: 아래 작은 글씨 '원래 구매를 찾지 못했어요' 대신 위에 [구매에서 고르기 | 분류 직접 고르기] 탭. 분류만 있는 환불은 수정할 때 '분류 직접 고르기' 탭으로 열림.
- [ ] **'고정지출' 분류 없애기** ⚠️ 배포할 때 Supabase에서 `0006_no_fixed_category.sql` 실행 필요:
  - 고정 항목인지는 분류가 아니라 기록의 '고정 항목에서 들어옴(source=recurring)' 값으로 구분 → 고정비도 통신비·구독처럼 직접 고른 분류로
  - 고정 항목 추가 때 분류를 미리 고르지 않고, 안 고르면 저장 안 됨
  - SQL을 돌리면 예전 '고정지출' 분류는 지우지 않고 숨김 (지난 기록은 그대로). 고정 항목 목록에 '분류를 골라 주세요'가 뜨는 항목만 고쳐 주면 됨
  - 캡처 읽을 때 관리비·통신·보험을 '고정지출'로 짐작하던 것 없앰
  - 숨긴 분류는 자동으로 골라지지 않음: 같은 사용처의 지난 분류·자주 쓰는 내역이 '고정지출'이어도 비워 두고 직접 고르게
- [ ] **내역 검색은 고른 달에서 + 합계**: 검색해도 연월이 그대로 보이고, 그 달 안에서만 찾음('10월 2건'). 결과 맨 아래(없을 때도) '최근 1년에서 찾기' → 오늘부터 1년 전까지 찾고, 위 연월 자리가 '최근 1년 · < 10월로'. 달을 바꾸면 그 달에서 다시 찾음. 검색할 때만 필터 아래에 합계 한 줄(지출·수입, 0원은 숨김, [지출]/[수입] 필터 따라감, 환불은 캘린더처럼 지출에서 빼고 회색 '환불 ○원 빠짐'). 한 번에 1,000건까지(넘으면 안내).
- [ ] **메뉴 이동 시 다시 불러오기 줄이기**:
  - 캘린더·내역·통계·설정 화면을 닫지 않고 기억 → 돌아오면 보던 달·고른 날짜·스크롤 그대로, '불러오는 중' 없이 바로
  - 저장·삭제가 있었거나 1분이 지났거나 날짜가 바뀌었으면 돌아올 때 뒤에서 조용히 새로 받음
  - 분류·결제수단 목록은 한 번 받아 두고 같이 씀 (바꾸면 그때 다시)
  - 로그아웃하면 기억해 둔 화면·목록 모두 버림
