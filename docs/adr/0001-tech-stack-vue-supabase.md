# ADR 0001. 기술 구성: Vue + Supabase

- 날짜: 2026-10-16
- 상태: 결정됨

## 배경
- 혼자 쓰는 가계부 웹앱을 최소 버전부터 빠르게 만들어 바로 쓰기 시작하려 한다.
- 지켜야 할 조건
  - 운영비 0원
  - 웹앱, 폰과 PC 모두에서 사용
  - 기기를 바꿔도 데이터가 남아야 한다

## 검토한 후보
| 후보 | 요약 | 결과 |
|---|---|---|
| A. Vue + Spring Boot + PostgreSQL | 가장 익숙하지만, 항상 켜진 서버를 0원으로 직접 운영·관리해야 하고 로그인도 직접 구현해야 함 | 탈락 (1차가 무거워짐) |
| B. Vue + Supabase | PostgreSQL·로그인·파일 저장을 무료 요금제로 제공, 서버 관리 불필요 | **채택** |
| C. 서버 없이 브라우저 저장 | 가장 간단하지만 폰·PC가 따로 놀고 데이터 유실 위험 | 탈락 ('기기를 바꿔도 데이터 유지' 위반) |

## 결정
- 화면: Vue
- 데이터·로그인·파일: Supabase (무료 요금제)

## 이유
- 로그인이 기본 제공되어 폰·PC 동시 사용과 기기 변경 문제를 한 번에 해결한다.
- 데이터베이스가 PostgreSQL이라 익숙하다.
- 서버를 직접 운영하지 않아 1차를 빠르게 만들 수 있다.
- 무료 요금제(DB 500MB, 파일 1GB)가 혼자 쓰는 가계부에 충분하다.

## 감수하는 점과 대책
| 감수하는 점 | 대책 |
|---|---|
| 일주일 동안 사용이 없으면 프로젝트가 일시 정지됨 (데이터는 남고 다시 켤 수 있음) | 주간 정리 알림(④ 단계)으로 꾸준히 사용, 정지 경고 메일이 오면 대시보드 접속 |
| 무료 요금제에 자동 백업 없음 | CSV 내보내기(② 단계)로 직접 백업 |
| Spring Boot를 쓰지 않음 | 나중에 서버 기능이 필요하면 별도로 붙인다 |

## 다시 검토할 때
- 무료 요금제 조건이 바뀌었을 때
- 이미지 읽기(③ 단계)에 서버 처리가 꼭 필요해졌을 때
